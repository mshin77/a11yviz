# a11yviz: Accessible Themes, Palettes and Audits for 'ggplot2' and 'plotly'

Tools for making ggplot2 and plotly charts more accessible to readers
with low vision, color-vision differences, and screen-reader users.
Functions return standard ggplot or plotly objects so existing code
keeps working. The accessible CSS also styles DT tables and DiagrammeR
diagrams that appear alongside charts in Quarto and Shiny documents.
